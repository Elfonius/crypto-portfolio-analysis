## Design rules used

- One finding per chart; title states the finding.
- Source/date footer; synthetic data label.
- Bars start at zero; log scale only for exit days and labeled.
- No 3D, no pie, no unlabeled dual axis.
- Color is secondary; labels and position carry the message.
- Exact values remain in the report tables.

These charts are illustrative. Do not copy their values or conclusions.
