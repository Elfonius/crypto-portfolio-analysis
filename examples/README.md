# Examples

These are synthetic examples, not real portfolios.

- `sample-report-en.pdf` — eight-page rendered full review; the best starting point for seeing the output.
- `sample-report-en.html` — styled HTML source used to render the PDF.
- `sample-review-tr.md` — full review in Turkish.
- `sample-review-en.md` — full review in English; the PDF is generated from this content.
- `sample-quick-screen.md` — one-page quick screen.
- `charts/` — ten synthetic visual-pack examples with a chart index.

They demonstrate the output shape: IPS-lite, data coverage, concentration, performance, risk, liquidity, scenarios, alternatives, decision record, sources, and limitations.

Every number is illustrative. Do not copy a position size or a verdict from an example.
